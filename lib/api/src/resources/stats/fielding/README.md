# Fielding Statistics GraphQL Operations

This directory contains GraphQL operations for fielding statistics:

- `seasonFielding.fragment.graphql` - Season fielding statistics fragment
- `careerFielding.fragment.graphql` - Career fielding statistics fragment
- `getPlayerSeasonFielding.query.graphql` - Player's season fielding stats
- `getPlayerAllSeasonFielding.query.graphql` - All season fielding stats for a player
