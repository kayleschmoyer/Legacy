# Batting Statistics GraphQL Operations

This directory contains GraphQL operations for batting statistics:

- `seasonBatting.fragment.graphql` - Season batting statistics fragment
- `careerBatting.fragment.graphql` - Career batting statistics fragment
- `getPlayerSeasonBatting.query.graphql` - Player's season batting stats
- `getPlayerCareerBatting.query.graphql` - Player's career batting stats
