# Pitching Statistics GraphQL Operations

This directory contains GraphQL operations for pitching statistics:

- `seasonPitching.fragment.graphql` - Season pitching statistics fragment
- `careerPitching.fragment.graphql` - Career pitching statistics fragment
- `getPlayerSeasonPitching.query.graphql` - Player's season pitching stats
- `getPlayerAllSeasonPitching.query.graphql` - All season pitching stats for a player
