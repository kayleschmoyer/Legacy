# Player GraphQL queries and fragments

This directory contains all GraphQL operations related to player data:

- `player.fragment.graphql` - Core player fields fragment
- `getAllPlayers.query.graphql` - Query to fetch all players
- `getPlayer.query.graphql` - Query to fetch a single player by ID
- `getPlayerByBrefId.query.graphql` - Query to fetch a player by Baseball Reference ID

## Usage

All player-related GraphQL operations should be defined in this directory to maintain organization by resource type.
