## Domain rules that live only in code

These are scoring-relevant behaviors with **no architecture doc** — the pointers below are the documentation. When output looks "random" or "wrong" in these areas, read the cited source before filing a bug.

| Rule                                     | Behavior                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Source                                                                                                                                                                                                                                    |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| SP probabilistic starts                  | A starting pitcher is selected for a given game-night with probability `P = startsNeeded / gamesRemaining` (always selected when `startsNeeded >= gamesRemaining`), capped by `leagues.pitcher_starts_per_matchup` (default 1). SP games are drawn only from games where `GS = 1`; RP only `GS = 0` (or `NULL` for unparsed historical data); all other positions get a game every night. Skipped SP nights set `matchup_player_games.sp_skipped = true` | [`lambdas/game-selection/src/services/season-game-selector.ts`](../../../../lambdas/game-selection/src/services/season-game-selector.ts) — search `startsNeeded`                                                                          |
| Position eligibility (hybrid)            | A player is eligible at a position with **≥ 10% of career games there OR ≥ 100 games** (integer math `g * 10 >= total_g`; replaced the old flat 50-game rule). SP requires `GS`, RP requires `g - gs` under the same thresholds. Materialized as `player_eligible_positions`                                                                                                                                                                             | Migrations `20260214_000000_update_eligible_positions_threshold.ts` (rule) and `20260302_120000_materialize_player_eligible_positions.ts` (materialization) in `lib/db-client/migrations/`                                                |
| Football auto-pick uses MOCK projections | The football draft strategy fills QB → RB → WR → TE → K → DEF → FLEX → BENCH using **mock** projected fantasy-points-per-game (hardcoded archetype baselines + deterministic per-`playerId` jitter) because real football projections do not exist yet. "Weird" football draft recommendations are usually this, not a bug                                                                                                                               | [`lambdas/db/src/schema/drafts/strategies/football.ts`](../../../../lambdas/db/src/schema/drafts/strategies/football.ts) — header comment                                                                                                 |
| "AI matchup recap" is not an LLM         | The premium `ai_matchup_recap` feature is a deterministic **template-based** narrative generator (template pick seeded by matchup id). There is no model integration to improve or debug                                                                                                                                                                                                                                                                 | [`lib/narrative/src/lib/narrative-generator.ts`](../../../../lib/narrative/src/lib/narrative-generator.ts)                                                                                                                                |
| Free-tier numeric limits                 | Max **3** non-mock leagues per free user, enforced atomically inside `createLeague`/`renewLeague` under `pg_advisory_xact_lock` (LS-5122 TOCTOU fix); **2** mock drafts per week (`MOCK_DRAFT_FREE_WEEKLY_LIMIT`)                                                                                                                                                                                                                                        | [`lambdas/db/src/schema/leagues/mutations.ts`](../../../../lambdas/db/src/schema/leagues/mutations.ts) — search `pg_advisory_xact_lock`; [`lambdas/db/src/schema/drafts/helpers.ts`](../../../../lambdas/db/src/schema/drafts/helpers.ts) |
