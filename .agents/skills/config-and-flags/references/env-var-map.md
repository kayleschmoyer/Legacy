# Per-project env-var consumption map

> Reference for [config-and-flags](../SKILL.md). Surveyed 2026-07-02 with all three access styles (dot, bracket, `getEnvVar*`); spec files excluded. Regenerate any row with:
>
> ```bash
> rg -oN "process\.env(\.[A-Z_][A-Z0-9_]*|\['[A-Z_][A-Z0-9_]*'\])" <project>/src --glob '!*.spec.*' | sort -u
> rg -n "EnvironmentVariable\.[A-Z_]+|getEnvVar" <project>/src --glob '!*.spec.*'
> ```
>
> To check whether Terraform actually sets a lambda var: `rg -n "<VAR>" terraform/`. A consumed var with zero Terraform hits is **dangling config** — undeployed or hand-configured; flag it, don't assume.
