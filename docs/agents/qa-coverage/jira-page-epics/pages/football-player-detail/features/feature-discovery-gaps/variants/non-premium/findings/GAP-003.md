# GAP-003 — Missed feature: Kicker (K) stats table with computed FG% (fgm / fga \* 100)

**Severity:** Medium
**Type:** Bug
**Agent lens:** Feature Discovery From Code
**Platform:** Web
**File:** `apps/web/src/pages/football/FootballPlayerDetailPage.tsx:227`

## Description

OffenseStatsTable for pos==='K' computes FG% client-side from kicking.fga and
kicking.fgm with a guard for fga > 0. Division-by-zero and null-safety logic is one
of the highest-risk single-line bugs but appears in no Feature Story. Existing
football-stats-breakdowns story names Passing/Rushing/Receiving only.

## Steps to Reproduce

1. Navigate to a kicker e.g. /football/players/<K_id> who has fga=0 (rookie or preseason)

## Expected

Documented story; 0-attempt kickers don't NaN%; FG% formats to 1 decimal.

## Actual

Untracked; null/zero edge unhandled by QA.

## Recommendation

Create Feature Story 'football-kicker-stats-breakdown' or extend
football-stats-breakdowns to list K, IDP, DST as explicit variants.
