# GAP-001 — Missed feature: IDP (DL/LB/DB) defensive stats table on player detail

**Severity:** High
**Type:** Bug
**Agent lens:** Feature Discovery From Code
**Platform:** Web
**File:** `apps/web/src/pages/football/FootballPlayerDetailPage.tsx:53`

## Description

IdpStatsTable renders Solo, Ast, Sacks, INT, FF for DL/LB/DB positions. The
football-stats-breakdowns feature story explicitly enumerates 'Passing / Rushing /
Receiving' (LS-5435 summary). IDP defensive stats are a separate, position-gated
render branch that QA inventory never lists. Non-premium and premium users viewing
any DL/LB/DB never get test coverage.

## Steps to Reproduce

1. Navigate to a defensive player detail e.g. /football/players/<LB_id>
2. Inspect the rendered career stats card

## Expected

IDP stats covered by a Feature Story with formatting, null-safety, and tier checks.

## Actual

No story; IDP-specific defects (e.g. wrong column for FF) would not be caught.

## Recommendation

Create Feature Story 'football-idp-stats-breakdown' with variants for DL/LB/DB null
stats, very-old-career players (career stats missing).
