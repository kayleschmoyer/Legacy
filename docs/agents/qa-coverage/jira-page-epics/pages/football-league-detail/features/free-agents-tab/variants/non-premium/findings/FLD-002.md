# FLD-002 — Shared Free Agents tab groups players as hitters/pitchers (baseball-only), no football position filters

**Severity:** High
**Type:** Bug
**Agent lens:** Cross-Platform Parity
**File:** `lib/shared-components/src/features/baseball/LeagueDetailFreeAgentsTab.tsx`, `apps/app/src/app/(app)/(tabs)/(home,leagues,players,games,you)/FreeAgents.tsx`

## Description

The Free Agents / Waivers Tab Feature Story (LS-5417) describes football position filters (QB/RB/WR/TE/K/DST/DL/LB/DB), name/team search, sort by projection, claim/add, and FAAB bidding for premium. The claim/add flow and FAAB bidding are implemented and correctly gated (`apps/app/src/app/(app)/(tabs)/(home,leagues,players,games,you)/FreeAgents.tsx` — `isFaab`, `renderClaimAction`). However, the underlying shared component both apps consume — `lib/shared-components/src/features/baseball/LeagueDetailFreeAgentsTab.tsx` (note: it lives under a `features/baseball/` directory despite being reused for football leagues) — only exposes a `handleGroup('hitters' | 'pitchers')` grouping toggle. There is no football position-group control (QB/RB/WR/TE/K/DST/DL/LB/DB) anywhere in the component, and no visible sort-by-projection control either. `apps/app/src/app/(app)/(tabs)/(home,leagues,players,games,you)/FreeAgents.tsx` passes `league.sport` through to the shared component but the component itself has no sport-conditional branching for its filter UI.

## Steps to Reproduce

1. Join or view a football league with waivers enabled, native app.
2. Navigate to the Free Agents / Waivers tab.
3. Look for position filters — only "Hitters" / "Pitchers" toggle is present (or whatever the component's default grouping renders for a non-baseball sport, which is itself unclear from the code).

## Expected

Football-specific position group filters (QB/RB/WR/TE/K/DST, and IDP positions DL/LB/DB where applicable) and a sort-by-projection control, per the Feature Story.

## Actual

Baseball-only hitters/pitchers grouping; football users get an irrelevant or possibly broken filter control.

## Recommendation

`lib/shared-components/src/features/baseball/LeagueDetailFreeAgentsTab.tsx` needs a sport-conditional grouping scheme (or should be relocated out of the `features/baseball/` directory and generalized) so it renders position-appropriate filters per `league.sport`. Given this touches a widely-shared component consumed by both platforms, recommend scoping this as its own ticket with explicit acceptance criteria for both baseball and football groupings, verified against the shared-components-first convention.
