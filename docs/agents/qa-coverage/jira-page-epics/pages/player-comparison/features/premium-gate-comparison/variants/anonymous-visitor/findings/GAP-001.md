# GAP-001 — Missed feature: Unauthenticated/anonymous PremiumGate copy variant ('Create a free account')

**Severity:** Medium
**Type:** Bug
**Agent lens:** Feature Discovery From Code
**Platform:** Web
**File:** `lib/shared-components/src/features/players/PlayerComparison.tsx` (`SignInPrompt`)

## Description

The Player Comparison experience shows distinct copy — "Create a free account to
compare up to 4 players side-by-side with career stats, scoring projections, and
season breakdowns." with a "Get Started Free" CTA — to unauthenticated visitors
before any premium gate is reached. The `premium-gate-comparison` feature
(LS-5575) originally enumerated only the authenticated-free vs premium access
states, not the anonymous-visitor variant. An unauthenticated viewer is
short-circuited to `SignInPrompt` and never sees the premium chrome, so this is a
separate journey from the free-vs-premium upgrade path.

## Steps to Reproduce

1. Visit `/players/compare` while logged out.
2. Confirm the anonymous CTA copy ("Create a free account…") and the
   "Get Started Free" button.

## Expected

The `anonymous-visitor` variant is enumerated under `premium-gate-comparison`
and backed by a hermetic E2E test asserting the unauthenticated journey.

## Actual

The variant existed in code (`SignInPrompt`) but was never listed in the QA
inventory for `premium-gate-comparison`.

## Recommendation

Add the `anonymous-visitor` variant under `premium-gate-comparison`.

## Resolution

- Variant enumerated in
  `docs/agents/qa-coverage/jira-page-epics/pages/player-comparison/features/premium-gate-comparison/feature.md`
  (see the _Access-state variants_ table).
- Automated coverage already exists and is now attributed to this variant:
  `describe('Player Comparison – unauthenticated visitor @regression')` in
  `apps/web-e2e/src/tests/player-comparison.spec.ts` asserts the comparison tool
  is hidden when logged out and that the "Get Started Free" CTA is visible and
  navigates to `/`.
