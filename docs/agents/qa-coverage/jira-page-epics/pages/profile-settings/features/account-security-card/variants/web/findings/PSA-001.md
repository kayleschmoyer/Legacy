# PSA-001 — Web Sign-in Method is hard-coded to "Google OAuth"

**Severity:** Medium
**Type:** Bug
**Agent lens:** Cross-Platform Parity
**Platform:** Web
**File:** `apps/web/src/pages/profile/ProfileSettingsPage.tsx` (Account & Security card), `apps/app/src/app/(app)/(tabs)/(home,leagues,players,games,you)/profile-settings.tsx` (`signInMethodLabel`)

## Description

Web always shows "Google OAuth" while native derives the label from the user's linked identities. The Linked Identities card lets users connect Discord and disconnect Google, so the web label can contradict reality. Jira: LS-10618.

## Steps to Reproduce

1. Open `/profile/settings` as a user whose only linked identity is Discord.
2. Read the Account & Security card.

## Expected

Sign-in Method reflects linked providers, as on native (e.g. "Google, Discord").

## Actual

Always "Google OAuth".

## Recommendation

Derive the label from `useMyIdentitiesQuery` data on web and share the derivation with native; update `expectAccountSecuritySection` in `apps/web-e2e/src/pages/settings.page.ts`.
