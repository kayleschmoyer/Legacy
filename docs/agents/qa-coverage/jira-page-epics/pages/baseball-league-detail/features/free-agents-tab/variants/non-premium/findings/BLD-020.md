# BLD-020 — FAAB bid field visible to non-premium members in WaiverClaimModal when joining a league whose commissioner has FAAB enabled

**Severity:** Medium
**Type:** Bug
**Agent lens:** Security
**Platform:** All
**File:** `apps/web/src/pages/baseball/league-detail-v2/tabs/FreeAgents.tsx:481-488 + apps/web/src/features/baseball/WaiverClaimModal.tsx`

## Description

FAAB is gated server-side only on LEAGUE CREATION (`requireEntitlement(ENTITLEMENTS.faab_waiver_type)`).
Joining a league that the commissioner created with FAAB is unrestricted. A free-tier user who joined
a premium commissioner's FAAB league participates in FAAB bidding fully.

## Steps to Reproduce

1. As a premium user, create a league with FAAB waivers.
2. As a free user, join via invite code (KI-001 allows bypass of join cap).
3. Click Claim on a free agent — WaiverClaimModal renders with a $ bid input.
4. Submit a bid — succeeds.

## Expected

Documented policy: FAAB participation is permitted for non-premium members of premium-FAAB leagues.

## Actual

Undocumented free participation in a premium-commissioner-created feature.

## Resolution

**Policy decision (LS-5922):** `faab_waiver_type` is intentionally a commissioner-creation-only
entitlement. Members who join a FAAB league created by a premium commissioner are permitted to
participate in FAAB bidding regardless of their own subscription tier. This is the
"commissioner pays, members participate free" model — consistent with how other league-wide settings
work (salary cap, playoff format, etc.).

The entitlement label for `faab_waiver_type` has been updated to
`'FAAB waiver type (commissioner league-creation only; members of FAAB leagues may participate regardless of tier)'`
to make this explicit in error messages and documentation.

See also: `docs/product/NonPremiumClaudeIssues.md` for the full policy reference.
