# GAP-003 — Missed feature: League Trade Block asking-price management UI

**Severity:** Medium
**Type:** Bug
**Agent lens:** Feature Discovery From Code
**Platform:** Web + Android Native
**File:** `lib/shared-components/src/features/matchup/LeagueTradeBlock.tsx:1`

## Description

The `trade-center-overview` feature story (LS-5680) mentions "Trade block" as one
of the five sections in TradingCenter but does not enumerate the following
sub-features that are fully implemented in `LeagueTradeBlock.tsx`:

1. **Set/Edit asking price** — team owners and assistant managers can set a free-text
   asking price on any of their own players who are on the trade block. The inline
   input is shown/hidden via an "Edit Price" / "Set Price" toggle button per row.
2. **Remove from trade block** — a "Remove" button per own-player row calls
   `setTradeBlock({ onTradeBlock: false })`.
3. **Asking price display** — the DollarSign icon + "Asking: <price>" label shown
   beneath the player name on any row that has a price set.
4. **Expandable list** — only the first 5 players are shown by default; a "Show
   N more" / "Show fewer" toggle reveals the remainder.
5. **Error state** — mutation errors surface a red role="alert" message at the top
   of the card.
6. **Player count badge** — a "N available" badge appears in the Trade Block header
   when at least one player is listed.

None of these six sub-features have QA acceptance criteria.

## Steps to Reproduce

1. Add two own-roster players to the trade block via the Roster page.
2. Open the Trades tab → scroll to Trade Block.
3. Observe count badge, player rows, "Set Price" and "Remove" buttons.
4. Press "Set Price" → observe inline input + "Save" button.
5. Enter a price and save — observe asking price displayed.
6. If > 5 players are on the block, observe the "Show N more" button.

## Expected

Each sub-feature has at least one unit-test assertion or E2E scenario.

## Actual

`trade-center-overview` (LS-5680) lists "Trade block" without any detail — no

Expand acceptance criteria in LS-5680 (or create a dedicated Feature Story
