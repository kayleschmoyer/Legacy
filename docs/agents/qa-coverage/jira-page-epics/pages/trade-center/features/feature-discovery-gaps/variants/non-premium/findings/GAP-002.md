# GAP-002 — Missed feature: Premium Trade Tools panel (Trade Analyzer + Value Calculator)

**Severity:** Medium

**Platform:** Web + Android Native
**File:** `lib/shared-components/src/features/leagues/PremiumTradeTools.tsx:1`

## Description

`PremiumTradeTools` is a collapsible panel rendered at the bottom of every
`TradingCenter` instance. It contains two sub-tools, neither of which appears
in the existing QA inventory for the Trade Center:

1. **Trade Analyzer** — select any pending trade offer from a picker, then view
   a per-player positional-value breakdown (`ValueBar` bars for "You Give" /
   "You Get") and a fairness verdict (`fair`, `slight-edge-you`,
   `strong-edge-you`, `slight-edge-them`, `strong-edge-them`) computed from the
   `POSITION_VALUES` scarcity table.

2. **Value Calculator** — reference table of per-position scarcity scores for
   both baseball and football; toggled by a sport selector. Helps users
   understand why certain positions command higher value in a trade.

Both tools are premium-gated: non-premium users see a lock overlay with an
"Upgrade to Premium" CTA button; premium users see the full tool set. The
section header is a toggle button that expands/collapses the panel.

The existing feature stories (`trade-center-overview` LS-5680, `submit-new-trade`
LS-5678) make no mention of this panel or its two tools.

## Steps to Reproduce

1. Open the Trades tab for a league with at least one pending trade offer.
2. Scroll to the bottom of the TradingCenter — observe the "Premium Trade Tools"
   collapsible section.
3. **Non-premium path**: press the section header to expand — observe lock
   overlay and "Upgrade to Premium" button.
4. **Premium path**: press the header to expand — observe two tabs ("Trade
   Analyzer" and "Value Calculator").
5. In Trade Analyzer: select a pending offer and observe value bars + verdict badge.
6. Switch to Value Calculator: toggle between baseball and football, observe
   position scarcity table.
