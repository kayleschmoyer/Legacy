# GAP-002 — Missed feature: 300ms search debounce with separate debounced cursor reset

**Severity:** Medium
**Type:** Bug
**Agent lens:** Feature Discovery From Code
**Platform:** Web
**File:** `apps/web/src/pages/football/FootballPlayersPage.tsx:41`

## Description

Search debounces at 300ms; on debouncedSearch change, cursor and allNodes are reset
(line 44-56). nfl-player-search feature story covers search but not the debounce
timing or the reset-on-change behavior, which is the source of common UX bugs (e.g.
typing fast then hitting Load More).

## Steps to Reproduce

1. Type a query fast in the search input
2. Within 300ms, click 'Load more' from the previous results

## Actual

Add a variant to nfl-player-search covering debounce window + cursor-reset interaction.
