# Operations Runbooks

This directory contains oncall runbooks — step-by-step procedures for operational tasks that require direct database or infrastructure access.

Each runbook documents: when to use it, prerequisites, exact steps, how to verify success, and how to roll back.

## Runbooks

| Runbook                                           | Summary                                                   |
| ------------------------------------------------- | --------------------------------------------------------- |
| [Promote user to admin](promote-user-to-admin.md) | Grant a user `admin` access level in `app_internal.users` |
