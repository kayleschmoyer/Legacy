## 💡 Common Tasks

### Build is Slow

1. Check [Nx Cloud Optimization Strategy](nx-cloud-optimization-strategy.md)
2. Verify cache configuration
3. Review [Nx DTE Badge Implementation](nx-dte-badge-implementation.md) status
4. Check [Nx Cloud Quota Fix](nx-cloud-quota-fix.md) for quota issues

### Nx Cloud Not Working

1. Review [Nx Cloud Conditional Usage](nx-cloud-conditional-usage.md)
2. Check access tokens and credentials
3. Verify quota in [Nx Cloud Quota Fix](nx-cloud-quota-fix.md)
4. Consult [Nx Cloud CI Strategy](nx-cloud-ci-strategy.md)

### Set Up New Package

1. Follow [Package.json Standards](package-json-standards.md)
2. Configure build scripts per [Script Cleanup Summary](script-cleanup-summary.md)
3. Add tests per [Jest Changed Files Config](jest-changed-files-config.md)

### Run Tests Efficiently

1. Use [Jest Changed Files Config](jest-changed-files-config.md) for speed
2. Configure E2E per [E2E Testing Migration](e2e-testing-migration.md)
3. Follow [Nx Best Practices](nx-best-practices-assessment.md)
