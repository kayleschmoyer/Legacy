Three ways to make the board say more

Same grid geometry, same 12-team snake — but the player, not the position, carries the cell. Each option adds a different second layer of information: who they were, where they ranked, and whether the pick was a steal. Horizontal scroll inside each board is intentional; that's how it behaves in the real layout.

A

Player-first card

Name becomes the headline. Position drops to a one-line footnote next to the real club and career window, and each cell carries one signature stat. Pick number shrinks; a value chip shows how far off consensus the pick was. Cheapest change — same cell, better hierarchy.

B

Ranked scoreboard

Every pick shows where it sat on the big board. A rank plate anchors the left of the cell, so scanning a column tells you the quality of a team's haul, not just its shape. Team headers gain roster-fill dots — red means an unfilled required slot — so needs read at the top instead of in a side panel.

C

Value heat board

The board becomes an argument. Cells are tinted by pick value — rank minus pick — so steals glow green and reaches glow red, and a footer totals each team's value earned. Reads at a glance from across the room; best if the league likes to trash-talk the recap.
