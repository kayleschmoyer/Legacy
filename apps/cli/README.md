# cli

Command-line interface for administrative tasks, data loading, user management, and debugging the Legacy Sports platform.

## Quick Start

```powershell
# Build the CLI
pnpm exec nx build cli

# Run a CLI command
pnpm exec nx run cli:<command>
```
